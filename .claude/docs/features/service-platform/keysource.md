# Источники ключей (`KeySource`)

Часть фичи `service-platform` — сначала [`index.md`](index.md).
Не навязываем один способ задать ключ — потребители разные. Абстракция
**`KeySource`** (интерфейс домена) с несколькими реализациями, выбираемыми
потребителем, плюс опциональный встроенный keystore. Добавить источник (Vault,
KMS) = новая реализация `KeySource` **без изменения операций**.

## Режимы

| Режим | Как задаётся ключ | Кому подходит | Безопасность |
|-------|-------------------|---------------|--------------|
| **Inline** | PKCS#12 (base64) + пароль **в запросе** | Быстрый старт, stateless | Секрет в запросе → **только по TLS/локальному сокету**; не логировать; в памяти эфемерно |
| **Путь на сервере** | путь к `.p12` + пароль из секрета/env | Сервер владеет ключами | Пароль вне запроса |
| **По `keyId`** | ссылка на запись в настроенном keystore | Централизованное управление | В запросе только `keyId`, без секретов |
| **Аппаратный токен** | тип хранилища (`KCST_KAZTOKEN`/`KZIDCARD`/…) + PIN | Токены / ID-карты | PIN — секрет; те же правила |
| **Встроенный keystore** | наш простой зашифрованный стор + admin-API/CLI (`add`/`list`/`remove`) | «Из коробки» | Мастер-ключ/пароль стора вне репо |

## Правила

- **Встроенный keystore — опциональный компонент, по умолчанию выключен.** Для тех,
  кто не хочет строить своё хранилище. Формат/шифрование стора и модель admin-
  доступа ещё не зафиксированы (см. открытые вопросы в [`../../architecture.md`](../../architecture.md)).
- **Единый интерфейс для `core`:** операции не знают, откуда пришёл ключ.
- **Во всех режимах пароли/PIN/материал ключа — секреты** (см.
  [`observability-security.md`](observability-security.md)): не попадают в логи,
  метрики, трейсы, тела ошибок и эхо-ответы; хранятся в памяти эфемерно и затираются
  после использования, насколько позволяет рантайм.
- **Секреты — только из env/файлов-секретов/секрет-менеджеров**, не из аргументов
  CLI и не из репозитория.
- **Типы токенов** (`KCST_*`) и загрузка хранилища — механика драйвера; см.
  [`../../kalkan-api/loading.md`](../../kalkan-api/loading.md).

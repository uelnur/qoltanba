# Kalkan C-API — самодостаточный справочник

**Scope.** Всё, что нужно, чтобы работать с нативной библиотекой Kalkan
(`libkalkancryptwr-64.so` / `KalkanCrypt.dll`) напрямую через её C-API, **не
открывая другие места**: как загрузить, как вызывать, полный перечень функций,
флагов, свойств и кодов ошибок, и рецепты операций. Значения сверены с заголовком
SDK `KalkanCrypt.h` (потребитель получает его вместе с библиотекой); поведение —
из прогонов против реальной библиотеки v2.0.13 на тестовых ключах НУЦ РК всех
профилей. Справочник **самодостаточен** — работать по нему, не заглядывая в код.

Роли/OID/алгоритмы РК (не относятся к самому API) — в
[`../nuc-pki-reference.md`](../nuc-pki-reference.md).

## Как устроен API

Один экспортируемый символ — **`KC_GetFunctionList`** — отдаёт указатель на
структуру `stKCFunctionsType` с указателями на все методы. Ты не линкуешься с
именами функций; ты `dlopen`-ишь либу, берёшь таблицу и зовёшь через неё.

```
dlopen(lib, RTLD_NOW|RTLD_GLOBAL)          загрузка (+ зависимости среды)
   └─ KC_GetFunctionList(&kc)              таблица указателей на методы
        └─ kc->KC_Init()                   однократная инициализация
             ├─ kc->KC_LoadKeyStore(...)   открыть ключ (PKCS12/токен) → alias
             ├─ kc->SignData / VerifyData / SignXML / X509CertificateGetInfo / …
             └─ kc->KC_XMLFinalize(); kc->KC_Finalize()   завершение
```

Жизненный цикл: **load → `KC_Init` → (много операций) → `KC_XMLFinalize` +
`KC_Finalize`**. Всё остальное — вызовы методов из таблицы.

## Соглашения вызова (важно — иначе SIGSEGV/мусор)

- **Буфер + длина «туда-обратно».** Строковые/бинарные выходы: передаёшь буфер и
  `*outLen`, куда кладёшь **ёмкость** буфера; либа перезаписывает `*outLen`
  фактически записанной длиной. Мало места → `KCR_BUFFER_TOO_SMALL` (увеличить и
  повторить, либо сперва вызвать с маленьким буфером ради нужной длины).
- **Строки NUL-терминированы в дополненных буферах** → всегда режь по первому
  `\x00` (иначе тащишь хвост мусора).
- **Проверяй `outLen < ёмкости` перед разбором.** При ошибке в буфере может лежать
  мусор; разбор такого (напр. `X509CertificateGetInfo` по битому серту) роняет
  либу в SIGSEGV. Разбирай выход только при `rc==0 && 0 < outLen < cap`.
- **`alias`:** для PKCS12 `KC_LoadKeyStore` возвращает alias (на тестовых ключах —
  **пустая строка**); подпись зовётся с этим alias, а verify/extract — с **пустым**
  alias `""`.
- **Успех = `rc == 0` (`KCR_OK`)**, а не текст. `outVerifyInfo` даже на успехе
  несёт OpenSSL-строку `error:00000000:...` (нули = «нет ошибки»).
- **Флаги sign и verify должны совпадать** — иначе `0x08F00039`
  (`KCR_SIGNFORMMAT`). См. [`signing.md`](signing.md).

## Gotchas (не выводится из заголовка)

- **Голого OpenSSL 3 недостаточно.** Либе нужен OpenSSL-**1.1**-форк
  `libkalkancrypto.so` из комплекта (символы `SRP_*`, удалённые в 3.x) + GNU
  libiconv + pcsclite + libm. Без них `dlopen` падает. → [`loading.md`](loading.md).
- **Таблица функций растёт между версиями** (`UVerifyData`, zip-методы,
  `KC_InitDebug` добавлены позже, в хвост структуры). Старая либа вернёт **короткую**
  таблицу — чтение хвостовых указателей небезопасно. Фиксируй минимальную версию.
- **Индексы подписей `1-based`** в `KC_GetCertFromCMS`/`KC_getCertFromXML`, но
  `VerifyData` берёт `inCertID` как **0-based** (проверено). Не путать.
- **Проверка срока идёт по системным часам** — без флага `KC_NOCHECKCERTTIME`
  подпись падает `0x08F00042` (`KCR_CERTTIMEINVALID`).
- **`X509ValidateCertificate` по OCSP возвращает `0` (good) / `1` (revoked)** —
  это НЕ коды `KCR_CERT_STATUS_*`; статус читается из rc **и** текста `outInfo`.
- **Версии в API нет функции** — определять по имени файла/конфигу/эвристике.

## Хелперы (нужны почти в каждом вызове)

Выходные буферы приходят NUL-терминированными и (для `X509CertificateGetInfo`) в
форме `имя=значение` — две операции, которые повторяются везде:

```go
// trimNul: обрезать C-строку по первому NUL (буфер дополнен нулями).
func trimNul(b []byte) []byte {
    if i := bytes.IndexByte(b, 0); i >= 0 { return b[:i] }
    return b
}

// afterEq: срезать префикс "имя=" (X509CertificateGetInfo отдаёт "C=KZ" и т.п.).
func afterEq(s string) string {
    if i := strings.IndexByte(s, '='); i >= 0 { return strings.TrimSpace(s[i+1:]) }
    return strings.TrimSpace(s)
}
```

Разбирай выход только при `rc==0 && 0 < outLen < cap` — иначе в буфере может быть
мусор, а последующий разбор роняет либу (SIGSEGV).
